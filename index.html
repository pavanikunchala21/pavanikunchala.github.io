Latest Projects — Detailed case studies (STAR)

E-Commerce Backend System

Problem solved: Reliable catalog, cart & order microservices for a medium-size online shop
Repo
STAR Case Study

Situation: A local retailer wanted to scale online sales with a modular backend that could handle concurrent orders and inventory updates without conflicts.

Task: Design and implement a microservice-based backend: Product, Cart, Order, and Auth services with reliable data consistency and REST API contracts for front-end consumption.

Action: I designed DB schemas (MySQL) and used Spring Boot services for each bounded context. Implemented optimistic locking for inventory updates, event-driven order processing, transactional boundaries via Spring transactions, and JWT-based authentication. Wrote integration tests and created OpenAPI docs for the APIs.

Result: The system supported 500 concurrent checkouts in load tests with zero inventory inconsistencies. Response times during peak load remained within SLA (p95 < 320ms).

Real-Time Chart Application

Problem solved: Live metric streaming for dashboards and alerts
Repo
STAR Case Study

Situation: A product manager needed a live view of system metrics (requests/sec, errors, latency) to make operational decisions.

Task: Build backend endpoints and a streaming interface that feeds the frontend charts in near real-time with minimal latency.

Action: Implemented a Spring Boot service exposing WebSocket endpoints and REST fallback. Backend collected metrics from simulated event producers and streamed aggregated values over WebSockets; added batching and compression to reduce bandwidth. Authenticated WebSocket sessions and provided reconnect logic on the client side. Added an API to query historical windows for charts.

Result: Frontend charts displayed updates in <200ms after metric ingestion on average. The streaming approach reduced REST polling overhead by 92%.
